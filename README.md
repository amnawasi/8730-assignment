## Project Overview
Evaluating SmartCentres Real Estate Investment Trust (SRU.UN) as an investment, using yfinance,
the Bank of Canada Valet API, a wowa.ca REIT comparison scrape, and SEDAR+ filings. Structured
data (prices, rates, peer comparison table) is stored in MySQL. Semi-structured and unstructured
data (fundamentals, news, filings) is stored in MongoDB, linked by a shared `company_id` key.
